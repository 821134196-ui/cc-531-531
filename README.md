# 种蛋孵化台账

按**来源鸡群、收集日期、储存温度、孵化箱批次**登记种蛋，贯穿「入孵 → 照蛋 → 出雏 → 健康复核」全流程的本地化台账系统。
零第三方依赖，仅用 Python 3 标准库 + SQLite + 原生前端。

## 一条命令启动

```bash
./run.sh                # 默认 http://127.0.0.1:8000，首次启动自动建库并写入演示数据
PORT=8123 ./run.sh      # 指定端口
```

演示数据包含一条完整的**孵化箱中途停机处置样例**：
`B2026-STOP` 批次第 8 天 IQ-02 停电 → 自动立案 → 三盘应急转入 IQ-01（全程留痕）→ 逐盘照检 → 签收 → 空箱复机。

重置演示数据：

```bash
rm -f hatchery.db hatchery.db-wal hatchery.db-shm && rm -rf uploads && ./run.sh
```

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖 22 个用例：**阶段数量守恒、盘位独占（含两名操作员并发转盘）、储存超期阻断、角色权限**（饲养员/操作员不得代兽医签署）。

## 业务规则

| 规则 | 实现方式 |
|---|---|
| 数量每阶段对得上 | 所有数量变动写入追加式 `quantity_ledger`（入孵为正 / 损耗为负 / 健康雏·待观察收成 / 转盘恒 0）；照蛋三项必须等于托盘在孵数；出雏四项必须等于照蛋后结余，余额归零 |
| 损耗不能从历史删除 | 触发器禁止 `DELETE` 流水、禁止改写核心字段；冲正只能追加反向行（`reversed` 留痕） |
| 一盘蛋不能同时在两台机器 | `slot_occupancy` 实体表双向唯一 + `BEGIN IMMEDIATE` 事务 + 转盘乐观源盘位锁，两人并发转盘必有一个被拒绝 |
| 储存超期阻断 | 收集日到入孵超过 7 天禁止上盘；必须先登记并**签收**「储存超期」异常处置 |
| 六种异常均有处置记录 | 混放来源 / 储存超期 / 孵化箱中途停机 / 照蛋漏盘 / 托盘移位 / 破壳延期，`open → handled` 全程留痕 |
| 停机处置闭环 | 停机信号（模拟适配器）自动立案，停机箱禁止上盘/转入；未签收不能复机 |
| 照蛋漏盘 | 无照蛋记录且无已签收漏盘处置的托盘，阻断出雏 |
| 角色权限 | 操作员/兽医可登记操作；**健康结论仅兽医可签**，服务层与数据库触发器双重拦截，饲养员不能代签 |

## 交付物（页面与数据）

- **种蛋批次**：列表并列入孵数、照蛋停育/破损、弱雏、死胎、健康雏、待观察、结余与出雏率；详情含数量守恒漏斗（每根条标注计算基数）、托盘盘位、数量流水、异常记录、出雏录入与兽医复核。
- **孵化箱盘位图**：按「台 → 层 → 位」实际层架渲染，显示托盘编号、所属批次；点盘可照蛋/转盘；停机箱整体变红并展示处置入口。
- **照蛋记录**：受精/停育/破损逐盘登记，照片保存在本地 `uploads/photos/`；点击照片进入灯箱，可**并列放大比对**。
- **异常移盘**：转盘写位置流水，关联异常单号；并发冲突给出明确提示。
- **出雏统计**：健康雏、待观察（含破壳延期）、弱雏、死胎，提交即做守恒校验。
- **健康复核**：兽医签署（合格/有条件/驳回），签署后留名留痕。
- **温控与信号**：`hatchery/adapters.py` 为模拟适配器（温控 37.8℃±波动/告警、孵化箱停机注入），真实部署替换为串口/MQTT 即可。

## 配色与图表

白、炭灰为主，蛋壳绿 `#3f7d5c` 作少量强调；图表分类色（绿/蓝/陶土）已通过色盲（CVD ΔE≥16）与对比度校验，所有统计图均标注基数（分母）。

## 目录结构

```
hatchery/
  schema.sql    # 表结构 + 守恒/禁删/兽医签署触发器
  db.py         # SQLite 连接
  services.py   # 领域服务（守恒、独占、超期、权限）
  adapters.py   # 模拟温控 / 孵化箱信号适配器
  app.py        # stdlib HTTP：JSON API + 照片上传 + 静态页
  seed.py       # 演示数据（含停机样例，照蛋照片本地生成）
  static/       # 前端（盘位图/批次/异常/照片灯箱）
tests/          # 领域规则测试
run.sh          # 一条命令启动
```

## 常用接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/batches` `/api/batches/{id}` | 批次列表（含各阶段数量/出雏率）/ 详情（流水、照片、异常） |
| POST | `/api/batches` | 登记批次（头 `X-User-Id`） |
| POST | `/api/place` | 入孵上盘（超期/占用/停机校验） |
| POST | `/api/move` | 转盘（支持 `expected_slot_id` 乐观锁） |
| POST | `/api/candle` | 照蛋登记（multipart，可带照片） |
| POST | `/api/hatch` | 出雏统计（守恒校验） |
| POST | `/api/reviews` | 兽医签署健康结论（非兽医 400） |
| POST | `/api/incidents` `…/{id}/handle` | 异常登记 / 签收 |
| POST | `/api/incubator/stop` `/resume` | 停机信号 / 处置后复机 |
| GET | `/api/incubators` `/api/photos/{id}` `/api/temp` | 盘位图 / 照片 / 模拟温度 |
