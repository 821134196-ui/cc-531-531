# 种蛋孵化管理

种蛋从**登记 → 入孵 → 照蛋 → 出雏 → 健康复核**的全程台账系统。
零依赖：Python 3 标准库 + 原生 HTML/CSS/JS，SQLite 保存数量流水，照蛋照片存本地，
温控与孵化箱信号走**模拟适配器**（真实部署替换 `app/adapters.py` 两个类即可）。

## 启动（一条本地命令）

```bash
./run.sh            # 首次自动建库并生成样例（含孵化箱中途停机），http://127.0.0.1:8080
./run.sh --reset    # 重置样例数据后启动
HATCH_PORT=9000 ./run.sh
```

测试：

```bash
./run_tests.sh      # 数量守恒 / 盘位独占（含并发转盘）/ 超期阻断 / 角色权限
```

## 页面

| 页面 | 内容 |
|---|---|
| 种蛋批次 | 并列入孵数、无精/停育/破损、健康/待观察、出雏率；详情含各阶段去向图（标注基数）、只追加流水、照蛋照片（点击放大、上一张/下一张比对）、出雏统计、兽医签署 |
| 孵化箱盘位 | 按实际层架（6 层 × 8 槽）渲染托盘编号；点击托盘转盘/疏散；温控曲线与断电/复电信号 |
| 异常移盘 | 停机疏散、移位纠正、跨箱转盘全部留痕 |
| 处置记录 | 混放来源 / 储存超期 / 中途停机 / 照蛋漏盘 / 托盘移位 / 破壳延期 六类处置单闭环 |

顶栏可切换**兽医 / 操作员 / 饲养员**身份；权限由后端强制（前端切换仅用于演示，绕过前端直接调接口一样会被拒）。

## 样例数据

- **EP0001**：收集 13 天（超期，先处置后入孵）→ IQ-A 入孵 600 枚 → IQ-A **中途停机**、3 盘疏散至 IQ-B →
  照蛋（损耗 82：无精 36/停育 30/破损 16）→ 破壳延期 10 枚处置 → 出雏 486 健康 + 22 待观察（出雏率 81%）→ 兽医签署。
- **EP0002**：与 EP0001 不同鸡群同箱，自动开**混放来源**处置；含一次**托盘移位**按实物纠正；照蛋已收口，可现场操作出雏。
- **EP0003**：储存 10 天且无处置记录，入孵会被**超期阻断**。

## 关键规则（均在 `app/service.py`，测试覆盖）

- **数量守恒**：入孵托盘合计 = 登记数；照蛋四分类（受精+无精+停育+破损）= 在盘数；
  出雏三类（健康+待观察+破壳延期）= 照蛋后在孵数；漏盘时照蛋收口被阻断并自动开处置单。
- **流水只追加**：`quantity_ledger` 的 UPDATE/DELETE 由 SQLite 触发器直接拒绝，损耗只能以负数流水冲抵。
- **盘位独占**：`tray_positions` 部分唯一索引保证一槽至多一盘、一盘仅一个位置；
  转盘用 `BEGIN IMMEDIATE` + 行版本号 + 唯一索引，两名操作员同时抢同一槽位时恰有一个成功、一个收到 409。
- **超期阻断**：储存 > 7 天的种蛋入孵被拒绝，除非已有 `storage_overdue` 处置闭环。
- **角色权限**：登记/入孵/照蛋/转盘/处置需操作员或兽医；健康结论**仅兽医可签**，饲养员/操作员代签返回 403。

## 目录

```
app/db.py         SQLite 表结构 + 禁删/禁改触发器
app/service.py    业务规则与全部守恒/独占/权限校验
app/adapters.py   模拟温控（停机指数降温、复电升温）与信号适配器
app/photos.py     照蛋照片（本地 SVG，真实部署换相机上传）
app/seed.py       样例数据（含停机疏散全链）
app/server.py     http.server JSON API + 静态托管
app/static/       前端（无框架）
tests/test_domain.py  13 个规则测试
```
